사이트: https://eunygwon.github.io/WebNovelCovers/

- 검색창에서 작품명·그림작가·글작가·출판사·장르·해시태그를 한 번에 찾습니다.
- 카드를 누르면 원본 이미지와 상세 정보, 작가 소셜 링크, 플랫폼 링크, 이미지 출처를 봅니다.
- 구글 계정으로 로그인하면 좋아요와 즐겨찾기가 본인의 구글 드라이브에 저장됩니다. 사이트 서버에는 아무것도 저장하지 않습니다.

이미지는 각 플랫폼과 작가 게시물의 원본 주소를 그대로 불러오며, 저작권은 각 권리자에게 있습니다.
